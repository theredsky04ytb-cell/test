Réglages du site

📊 Statistiques de visites

Gratuit et sans cookie avec GoatCounter : créez un compte, choisissez un code (ex : monatelier) et recopiez-le ici. Laissez vide pour désactiver.

🧮 Estimateur de prix (page Sur-mesure)

Le client saisit les dimensions de son objet et voit une fourchette de prix (−20 % / +30 %). Réglez ici vos tarifs ; le devis final reste toujours à votre main.

Formule : poids estimé (volume × remplissage × densité) × prix/g + temps × tarif horaire, avec un minimum par pièce, plus les frais fixes.

Aide rapide

Fenêtre du produit

Un clic sur un produit ouvre sa fiche : grande image, nom, description détaillée et, si vous les avez renseignés, les problèmes possibles / conseils d'utilisation (champ « ⚠️ » de la fiche : une ligne = un point de la liste). Si la description détaillée est vide, la description courte est reprise.

Produit personnalisable

Dans la fiche d'un produit, activez ✨ Personnalisable puis décrivez ce que le client peut changer (une ligne = un point : texte, logo, photo, couleur…). Le produit reçoit un badge violet, un filtre « Personnalisables » apparaît dans le catalogue et la fiche affiche votre texte avec un avertissement automatique : la personnalisation doit être vérifiée avant l'impression et n'est pas toujours réalisable. Le bouton devient « Personnaliser » et le message envoyé invite le client à détailler sa demande.

Photos multiples, couleur, promo, nouveauté

  • Photos supplémentaires : jusqu'à 5 autres angles dans la fiche produit (diaporama qu'on fait glisser).
  • 🎨 Couleur au choix : le client choisit parmi vos filaments en stock de la même matière ; sa couleur est ajoutée au message de commande.
  • Ancien prix : renseignez-le pour afficher un prix barré et une pastille « −X % ». Videz-le pour terminer la promo.
  • 🆕 Nouveau : pastille automatique (à désactiver quand le produit n'est plus une nouveauté).
  • Dupliquer (icône copie) : crée une copie masquée à modifier avant publication.
  • 🇬🇧 Version anglaise : champs facultatifs en bas de la fiche, utilisés si le visiteur passe le site en anglais.

Galerie & avis

L'onglet « Galerie & avis » alimente un onglet public du même nom (il n'apparaît que s'il y a du contenu). Ajoutez vos belles réalisations en photo et de vrais avis clients.

Panier, favoris, estimateur, formulaire

  • Panier et favoris : automatiques, enregistrés dans le téléphone du visiteur. Le panier envoie un message récapitulatif (aucun paiement en ligne).
  • Estimateur : réglez vos tarifs dans Réglages. Le client voit une fourchette indicative, jamais un prix ferme.
  • Formulaire d'envoi de fichier : les demandes arrivent dans Netlify → Forms (fichier joint téléchargeable, 100 envois gratuits par mois). Pour être prévenu par e-mail : Forms → Form notifications → Add notification → Email.
  • Bandeau d'annonce et statistiques GoatCounter : dans Réglages.

Sauvegarde

Réglages → « Télécharger une sauvegarde » : un fichier unique avec tout (photos comprises). « Restaurer » le remet en place sur ce site ou sur un nouveau site. Faites-en une de temps en temps.

Masqué ou hors stock ?

  • Visible = désactivé → le produit est totalement invisible pour les clients (brouillon, produit retiré…). Il reste dans votre liste.
  • En stock = désactivé → le produit reste affiché, grisé avec « Hors stock ». Le client peut cliquer sur « Me prévenir ».

Enregistrement

Chaque action (interrupteur, ajout, suppression, déplacement…) est enregistrée automatiquement. Le statut en haut à droite indique « À jour » une fois sauvegardé. Les clients voient les changements dès qu'ils rechargent la page.

Filaments

L'onglet « Filaments » alimente la page publique du même nom : une pastille par couleur, classée par matière. Disponible désactivé = « Épuisé » (grisé). Visible désactivé = caché aux clients. Le tri est automatique (matière, disponibles d'abord, puis ordre alphabétique).

Photos

  • Dans la fiche produit, cliquez sur « Choisir une photo » : elle est redimensionnée et compressée automatiquement (format WebP, ~900 px).
  • Vous pouvez aussi coller une adresse d'image (https://…) ou un chemin local comme ./images/mon-objet.jpg.

Ordre d'affichage

Utilisez les flèches ↑ ↓ (filtre « Tous » et sans recherche). L'ordre est celui du site, avec les produits hors stock toujours placés en dernier.

Sécurité

  • Le mot de passe est défini dans Netlify : Site configuration → Environment variables → ADMIN_PASSWORD. Après modification, relancez un déploiement.
  • La session se ferme automatiquement après 12 h.
